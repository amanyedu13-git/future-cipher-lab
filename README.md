# Future Cipher Lab - Horoscope Landing Page

A modern, responsive horoscope landing page built with **TanStack Start**, **React**, and **Tailwind CSS**.

## 🚀 Features

- **Modern UI**: Clean and intuitive design using Radix UI and Tailwind CSS.
- **Animations**: Smooth transitions and animations powered by Framer Motion.
- **Responsive Design**: Optimized for all screen sizes, from mobile to desktop.
- **Fast Performance**: Built on top of Vite and TanStack Start for lightning-fast loading and SSR support.
- **Component-Based Architecture**: Modular components for easy maintenance and scalability.

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Components**: [Radix UI](https://www.radix-ui.com/)
- **Animations**: [Framer Motion](https://motion.dev/)
- **Forms**: [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)

## 📂 Project Structure

## 🏁 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (Latest LTS recommended)
- [Bun](https://bun.sh/) (Recommended package manager)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   bun install
   ```

### Running Locally

To start the development server:

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

### Building for Production

To create a production build:

```bash
bun run build
```
